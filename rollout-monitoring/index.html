RL Rollout 监控 · 资料索引为 Cursor onsite 准备的一组材料。题目是：给 40 多个 dataset 和它们的 RL rollout，找出里面的坏数据和 reward hacking，设计一个自动化监控系统。下面几个页面讲的是同一件事，只是详略和角度不同。

今晚建议这样读

  1. 先读人话版总结的开头三节：这道题要干什么、六大类问题的总地图、找到问题以后怎么判断是谁的锅。大约 20 分钟，读完就有了全局图。
  2. 再读Tool 专题，这是你决定重点做的方向。先看一览表和「工具调用账本」，再按组读，最后看通用识别法和面试讲法。
  3. 然后读人话版总结的后半部分：识别方法、系统设计、onsite 当天怎么推进、开场两分钟和追问，大约 50 分钟。
  4. 有余力再读完整版里的Cursor 自己公开过的坑，这是面试官团队自己写过的东西。
  5. 遇到看不懂的词，去术语小词典查。面试前一晚别熬太晚。
