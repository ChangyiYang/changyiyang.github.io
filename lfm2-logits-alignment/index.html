Diff

同一 token、同一权重

差异会进入 ratio、KL、clip 与 gradient。

Δₜ = log p_actor(aₜ | sₜ) − log p_rollout(aₜ | sₜ)

相同参数仍可能得到不同数值结果。batch shape、kernel、reduction order、dtype cast、cache path 都会改变最后几位，MoE router 随后把它放大。

Reusable method

最值得复用的七条定位方法

  1. 拆三条路径：actor、prefill、online。
  2. 固定 token：不同 generation 只提供方向性证据。
  3. 找第一处非 exact：最终 logits 无法定位。
  4. 保存 operator input/output：区分 seed 与 amplifier。
  1. 专门做反例：combine、M=1、cached actor、actor-loop。
  2. 验证诊断环境：Ray env、backend fallback、missing flag。
  3. forward/backward 分开验收：还要过 FSDP、tied weight、optimizer。

最有效的工作单位是一条可证伪假设、一个固定输入 paired experiment，再加一处明确 boundary。

Reproducibility

复现实验必须保留的条件

训练 / rollout

  • deterministic SGL inference
  • unified decode attention
  • 当前 image 的 non-AITER MoE fallback
  • ordered MoE contract
  • actor exact operator patches
  • trainer.save_freq=-1

验证 artifacts

  • prompt / response IDs 与 masks
  • actor / rollout chosen logprobs
  • route IDs、slot order、weights
  • selected operator boundaries
  • worker-side applied-patch logs
  • W&B timing + diff metrics

standalone test 需要复制 live run 的 dtype、backend、process-global deterministic overrides 与全部 opt-in flags。少一个条件就会变成另一套 contract。

Next steps

从 research path 走向可维护实现

1. 缩成最小 patch

分离 dump hooks、one-off scripts 与 operator patch；明确 SGL/verl 各自承担的 contract。

2. 建 CI correctness gate

短序列逐层 exact + 长序列 logprob distribution；缺 artifact 必须 fail closed。

3. 扩大覆盖

多 seed、batch shape、多 step、rollout n>1、TP/EP、更长 context。

4. Production benchmark

warmup 后重复测 throughput、memory、compile cost，逐项评估 accuracy flag。

当前 reference path 可以充当 oracle：任何性能优化都能直接检查它改变了哪一处 exact boundary。
