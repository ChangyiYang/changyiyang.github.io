## 新增一份 deck
把 HTML 放进一个新子目录即可，会自动出现在对应 URL：

```
changyiyang.github.io/
├── index.html            # 总目录页（新增 deck 时在这里加一张卡片）
└── <deck-name>/
    └── index.html        # → changyiyang.github.io/<deck-name>/
```
